# 🏏 IPL Data Analysis (2008–2020)

### 📌 About the Project

This project focuses on analyzing Indian Premier League (IPL) data from 2008 to 2020 to explore match statistics, team performance and player insights.

Developed as a college team project.

### 🎯 Objectives

* Analyze IPL match data from 2008 to 2020.
* Explore team and player performances.
* Identify trends and patterns in IPL matches.
* Present meaningful insights from the data.

### 📂 Project Files

* `ipl data analysis.pdf` – Project report and analysis.

2008–2020
